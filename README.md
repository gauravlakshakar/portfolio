# Gaurav Lakshakar — Portfolio

A responsive, static portfolio website designed for GitHub Pages.

The Work section initially shows three featured public GitHub repositories (AnyData Analyzer, Web Scraping & BI, and Automating Reporting). Use **See more** to expand the list. README overviews are extracted from each README (not generated by an LLM), and each full README can be expanded inline on its project card. Update a repository's `README.md` on GitHub and the portfolio will show the latest content on the next visit or refresh. If GitHub's public repository listing API is unavailable or rate-limited, a saved repository list is used while README content continues to load directly from GitHub.

The header theme picker switches the accent palette between mint, ocean, violet, and amber and remembers the selection in the browser.

## Files
- `index.html` — page content, SEO metadata, structured person data
- `styles.css` — responsive visual system and layout
- `interactive.css` — navigation tooltips, inline README panels, and contact form
- `script.js` — GitHub repository/README loading, mobile navigation, and contact form submission
- `thank-you.html` — confirmation page after a successful contact form submission
- `assets/Gaurav-Lakshakar-Resume.pdf` — résumé download

## Run locally
From this folder, start a local web server:

```powershell
python -m http.server 8000
```

Open `http://localhost:8000` in your browser. Stop the server with **Ctrl+C**.

## Deploy with GitHub Pages
1. Create a new public repository named `portfolio` (or use your preferred repository).
2. Upload the contents of this folder to the repository root. Make sure `index.html` is at the root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then Save.
6. GitHub Pages will publish the site at `https://<your-github-username>.github.io/portfolio/`.

For your existing user site repository `gauravlakshakar.github.io`, uploading these files to its root publishes at `https://gauravlakshakar.github.io/`.

## Before publishing
- Confirm that the project repositories are public and the links are correct.
- To update a project overview, edit or add `README.md` in that repository on GitHub. The portfolio reads it on each visit; no portfolio file edit is needed.
- Replace the résumé PDF when you update your résumé.
- The project cards link to their public repositories where available.
- Work, About, Toolkit, and Journey scroll to sections on the same page. Hover or keyboard-focus the section links for short descriptions.
- The GitHub profile photo is loaded from your public GitHub avatar.
- Volunteer and contributor messages are sent to `gauravlakshakar581@gmail.com` through FormSubmit. After a successful submission, visitors are redirected to `thank-you.html`. The sender's address is included as the reply-to so you can reply manually; no automatic reply is sent. On first use, the site owner must confirm FormSubmit's activation email before messages can be delivered. FormSubmit processes the submitted contact details.
- Complete FormSubmit's email activation before sharing the portfolio.
- This is a static portfolio; it needs no backend, GitHub token, or API keys. Live repository data and form submission require an internet connection.
